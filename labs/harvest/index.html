Capturing a useful HAR: in Chrome DevTools open Network, tick Preserve log, then right-click the request list and choose Save all as HAR with content. The plain “Save all as HAR” option omits response bodies, and without bodies schema inference degrades to a header-only spec (the coverage meter on the Spec tab will tell you when that has happened).

How the no-upload claim is enforced. This page ships connect-src 'none' in a <meta http-equiv="Content-Security-Policy"> tag in its own source, so the browser refuses every outbound connection regardless of what the JavaScript asks for. The counter in the header wraps fetch, XMLHttpRequest, WebSocket and sendBeacon and shows how many were attempted. View source, or open DevTools and watch the Network tab stay empty. This is a statement about this page — the CV homepage does fetch the GitHub API for its repository list.
