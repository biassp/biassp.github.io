DATA FIKTIF Seluruh pasien, dokter, diagnosis dan resep di halaman ini dibuat oleh algoritma. Tidak ada data pasien nyata, tidak ada NIK, tidak ada nomor BPJS yang berlaku — kolom identitas sengaja diisi string bertanda FIKTIF yang tidak mungkin valid di sistem mana pun. Data tersimpan di IndexedDB peramban Anda sendiri dan tidak pernah dikirim ke mana pun.

Masuk sebagai

Mengapa privasi adalah fiturnya, bukan hiasannya. Data kesehatan adalah data pribadi yang bersifat spesifik menurut UU 27/2022 tentang Pelindungan Data Pribadi, dengan kewajiban yang lebih berat daripada data biasa. Sebuah demo portofolio tidak punya alasan sah untuk menyentuh data pasien nyata dan tidak punya alasan sah untuk mengirim apa pun ke server. Halaman ini menegakkan hal itu dengan connect-src 'none' di dalam tag <meta http-equiv="Content-Security-Policy"> pada sumbernya sendiri: peramban menolak setiap koneksi keluar apa pun yang diminta JavaScript. Penghitung di kepala halaman membungkus fetch, XMLHttpRequest, WebSocket dan sendBeacon lalu menampilkan berapa kali dicoba. Buka DevTools, lihat tab Network tetap kosong. Ini pernyataan tentang halaman ini — beranda CV memang memanggil API GitHub untuk daftar repositorinya.
