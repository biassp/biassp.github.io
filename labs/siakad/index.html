Sistem informasi akademik SMP — penjadwalan, penilaian, rapor. Data fabrikasi, tidak keluar dari tab ini.

panggilan jaringan: 0 CV

Seluruh data di halaman ini fabrikasi. Nama peserta didik, guru dan orang tua disusun suku-kata demi suku-kata dari pola fonotaktik buatan; NISN diambil dari blok sintetis 99xxxxxxxx yang diterbitkan oleh kode ini sendiri; tidak ada NIK sama sekali. Tidak satu pun merujuk anak, guru atau sekolah yang nyata. Semuanya dibangun ulang dari satu bilangan seed setiap kali halaman dimuat.

Mengapa angka jaringan itu penting di sini. Ini catatan anak. Halaman ini memasang connect-src 'none' di dalam tag <meta http-equiv="Content-Security-Policy"> pada sumbernya sendiri, jadi peramban menolak setiap koneksi keluar apa pun yang diminta JavaScript-nya. Penghitung di header membungkus fetch, XMLHttpRequest, WebSocket dan sendBeacon. Buka DevTools, tab Network akan tetap kosong. Yang tersimpan hanya suntingan Anda, di IndexedDB, di peramban ini. Ini pernyataan tentang halaman ini — beranda CV di biassp.github.io memang memanggil GitHub API untuk daftar repositorinya.

Tanpa framework, tanpa bundler, tanpa dependensi, tanpa build step: guard.js, domain.js, data.js, solver.js, solver.worker.js, akademik.js, store.js, tests.js, app.js, app.css. README
